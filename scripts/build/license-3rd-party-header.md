This file is **auto-generated by SBOM tooling at release time** — specifically
`scripts/build/generate_sbom.py`, which runs
[`cyclonedx-py`](https://pypi.org/project/cyclonedx-bom/) (CycloneDX 1.6)
against the production virtual environment and merges in hand-maintained
non-Python components from `scripts/build/sbom-bundled.json`. The
machine-readable SBOM is committed at the repo root as
[`sbom.cdx.json`](sbom.cdx.json); this Markdown file is rendered from that
SBOM. **Do not edit either by hand** — regenerate with
`python scripts/build/generate_sbom.py` and commit the result.

The generator enforces a license deny-list (AGPL, SSPL, BUSL, Commons
Clause) and aborts the build if any Python or bundled component ships under
one of those terms. This guards against one-way-compatible licenses being
silently merged into a GPL-2.0-or-later distribution.

If you believe any third-party software is used by Resistine but is not
listed here, or if license information needs correction, please open an
issue at https://github.com/Resistine/Resistine-Desktop/issues.
